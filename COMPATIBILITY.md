# Compatibility

| Platform | Package and DOCX | Actual Codex install | Agent Skills install |
|---|---|---|---|
| Windows | Local validation and CI | Test from a clean marketplace install | Test all and single-skill installations |
| Linux | GitHub Actions matrix | Requires a Codex environment | GitHub Actions matrix |
| macOS | GitHub Actions matrix | Requires a Codex environment | GitHub Actions matrix |

The matrix describes coverage targets. Use the workflow run and release acceptance records for actual results. Automatic selection can vary with model, context and other installed skills.
